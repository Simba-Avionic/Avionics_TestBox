# Avionics TestBox

## What is it?

TestBox is an insert for a QBrick Toolbox that has every electronical component needed for a test (from the rocket side, GS is not included)

## Why was it created?

Mounting electronics to the static fire stand was an issue during three static fire tests of R7 Orzeł rocket
